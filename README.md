

#  SafeWalk — Route Safety Companion

### Pedestrian-First Navigation for Safer Journeys

SafeWalk is a pedestrian-focused navigation platform developed during **KATATHON 2025**. Instead of focusing only on the shortest route, SafeWalk considers multiple safety-related factors to help users choose a **safer walking route**.

The platform combines route information, traffic, weather, incident data, and user reports to generate safety-aware routes, along with features for emergency assistance.

 **1st Runner-Up — KATATHON 2025**

---

## 🎯 Problem

Traditional navigation systems primarily optimize for factors such as **distance and travel time**.

However, the shortest route is not always the safest route for a pedestrian.

SafeWalk addresses this problem by considering additional factors such as:

* Street lighting
* Incident history
* Traffic and congestion
* Weather conditions
* User-reported incidents
* Route safety information

The goal is to help users make **better-informed decisions while travelling on foot**.

---

## 🚀 Key Features

* 🗺️ **Safety-Aware Route Planning** — Helps identify safer walking routes rather than simply choosing the shortest path.
* 🚦 **Traffic & Congestion Analysis** — Uses traffic information to evaluate route conditions.
* 🌦️ **Weather-Aware Routing** — Incorporates weather information into safety considerations.
* 🚨 **Emergency SOS** — Supports SMS-based emergency alerts through Twilio.
* 🤖 **AI-Assisted Incident Classification** — Uses Gemini to assist with incident analysis.
* 🎙️ **Voice Safety Assistant** — Integrates ElevenLabs for voice-based safety interaction.
* 📍 **Real-Time Location & Route Information** — Provides route-related information through the mobile application.
* 📸 **Incident Reporting** — Supports user-generated reports and image uploads.
